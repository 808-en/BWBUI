Idea #1 · World Code

New API Functions for Building Shapes

Currently, building structures through World Code can involve creating individual blocks or using existing functions to generate relatively simple shapes. However, more advanced structures, especially triangular ones, can be difficult and time-consuming to create.

A possible solution would be to introduce new API functions that allow players to generate shapes using multiple coordinates. This could make it much easier to build triangles, pyramids, stars, and other complex geometric structures without manually calculating every individual block position.

How could it work?

A function could accept several coordinate positions, determine the area or shape between them, and automatically place the selected block type wherever necessary.

api.setBlockTri(pos1, pos2, pos3, blockName)

For example, this function could generate a filled triangular surface using three corner positions. Additional functions could later support more complicated shapes, including pyramids, polygons, and custom 3D structures.

Potential benefits and limitations

This would make building maps easier, reduce repetitive World Code, and allow players to create structures that would otherwise require complicated scripts or time-consuming work. However, generating large or complicated shapes could require significant processing time. Optimized algorithms and block limits could help prevent performance problems.

Idea #1 · File Tools

Schematic File Previewer & Converter

Working with schematic files can sometimes be inconvenient, especially when users want to inspect a build before downloading or importing it. It can also be difficult to know whether a file is compatible with the intended application or building tool.

BloxdHub could introduce a built-in schematic previewer that allows users to upload a supported schematic file and view its contents directly on the website. Instead of downloading a file and opening it in another program, users could quickly inspect the structure in an interactive 3D preview.

How could it work?

Users would upload or drag and drop a schematic file into the previewer. The website would read the file's block information, reconstruct the structure, and display it in a 3D viewer. Users could rotate the camera, zoom in, and inspect the build from different angles.

File conversion

The tool could also include a conversion feature, allowing supported schematic formats to be converted into other compatible formats. This would make it easier to transfer builds between different tools and building environments.

Potential benefits and limitations

A previewer would help users check their builds before importing them, while conversion tools could improve compatibility and accessibility. The main challenge would be supporting different schematic formats and handling large files efficiently. Clear file size limits and format compatibility information would make the tool easier to use.
